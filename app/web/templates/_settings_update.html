دستور آپدیت از ترمینال

آپدیت از داخل پنل غیرفعال است. روی سرور این دستور را اجرا کنید:

bash pgclock.sh update

یا از منوی مدیریت:

bash pgclock.sh
# سپس گزینه 2 — Update

نحوه آپدیت

  1. با SSH به سرور وصل شوید و به پوشه پروژه بروید.
  2. دستور bash pgclock.sh update را اجرا کنید.
  3. کد از GitHub گرفته می‌شود، وابستگی‌ها نصب می‌شوند و در صورت نصب بودن سرویس، خودکار ری‌استارت می‌شود.
  4. فایل .env و پوشه data دست‌نخورده می‌مانند.
  5. بعد از اتمام، این صفحه را رفرش کنید تا نسخه جدید دیده شود.

اگر بعد از آپدیت نیاز به ری‌استارت بود

معمولاً bash pgclock.sh update خودش سرویس را ری‌استارت می‌کند. اگر پنل یا ربات بالا نیامد، یکی از این‌ها را اجرا کنید: 

sudo systemctl restart pgclockbot

یا از منوی مدیریت اسکریپت:

bash pgclock.sh
# گزینه 5 — Service → Restart

برای دیدن لاگ:

journalctl -u pgclockbot -n 50 --no-pager
