شروع سریع

نصب، ویزارد اولیه و اولین ورود به وب‌پنل را قدم‌به‌قدم یاد بگیرید.

در پنل: / مخاطب: مالک، ادمین، نماینده، ادمین پاسارگارد، نماینده ارشد

این بخش برای کیست؟

همه نقش‌ها — مخصوصاً کسی که ربات را روی سرور نصب می‌کند.

نصب سریع

روی اوبونتو ۲۲٫۰۴ یا جدیدتر:

bash <(curl -fsSL https://raw.githubusercontent.com/Mrclocks/PGClockBot/main/get.sh)

منوی انگلیسی باز می‌شود. گزینهٔ Install را بزنید، بعد در مرورگر ویزارد را کامل کنید.

مثال واقعی

فرض کنید IP سرور شما 203.0.113.10 است:

  1. نصب را تمام کنید.
  2. بروید به http://203.0.113.10:9000/
  3. ویزارد: یوزر/رمز وب، توکن ربات، اتصال پاسارگارد را پر کنید.
  4. Finish بزنید و با همان یوزر وارد پنل شوید.

اگر پروژه از قبل هست

cd PGClockBot
bash get.sh
# یا
bash pgclock.sh

آپدیت: منو → Update (فایل .env حفظ می‌شود).

اولین کار بعد از نصب

  1. در تنظیمات ربات متن خوش‌آمد و دکمه‌ها را ببینید.
  2. یک پلن بسازید و به تمپلیت پاسارگارد وصل کنید.
  3. روش پرداخت (مثلاً کارت‌به‌کارت) را در تنظیمات پرداخت پر کنید.
  4. در تلگرام به ربات /start بزنید و خرید آزمایشی کنید.
خطای رایج

مشکل: صفحهٔ وب باز نمی‌شود یا Timeout می‌دهد.

علت رایج: فایروال پورت ۹۰۰۰ را بسته، یا سرویس بالا نیست.

راه حل:

bash pgclock.sh service
curl http://127.0.0.1:9000/health
sudo ufw allow 9000/tcp
خطای رایج

مشکل: ویزارد می‌گوید فقط با لینک یک‌بارمصرف.

علت رایج: از اینترنت بدون توکن gate باز کرده‌اید.

راه حل: روی سرور bash pgclock.sh status بزنید و لینک کامل را کپی کنید، یا از خود سرور با 127.0.0.1 باز کنید.
