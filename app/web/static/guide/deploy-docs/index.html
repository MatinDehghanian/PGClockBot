انتشار راهنما روی دامنه خودتان

چطور خروجی راهنما را روی سرور و دامنه شخصی بالا بیاورید.

در پنل: /help/ مخاطب: مالک، ادمین
<h2 id="راهنما-را-روی-دامنه-خودتان-بالا-بیاورید">راهنما را روی دامنه خودتان بالا بیاورید</h2> <p>خروجی آماده در پروژه اینجاست:</p> <p><code>app/web/static/guide/</code></p> <p>همین پوشه یک سایت استاتیک کامل است (HTML/CSS/JS/فونت).</p> <h2 id="روش-۱--آپلود-روی-هاست">روش ۱ — آپلود روی هاست</h2> <ol><li>داخل پروژه:</li></ol> <pre><code class="language-bash">python scripts/build_guide.py</code></pre> <ol><li>محتویات <code>app/web/static/guide/</code> را روی هاست دامنه خودتان بریزید.</li><li>دامنه را به همان پوشه اشاره دهید؛ مثلاً <code>https://docs.example.com</code></li></ol> <h2 id="روش-۲--nginx-روی-vps">روش ۲ — Nginx روی VPS</h2> <pre><code class="language-nginx">server { listen 80; server_name docs.example.com; root /var/www/pgclock-docs; index index.html; location / { try_files $uri $uri/ $uri/index.html =404; } }</code></pre> <p>محتویات <code>guide/</code> را در <code>/var/www/pgclock-docs</code> کپی کنید.</p> <h2 id="وصل-کردن-آیکون-؟-پنل-به-دامنه-شما">وصل کردن آیکون ؟ پنل به دامنه شما</h2> <p>در <code>.env</code> سرور ربات:</p> <pre><code class="language-env">DOCS_BASE_URL=&quot;https://docs.example.com&quot;</code></pre> <p>سرویس را ری‌استارت کنید. از این به بعد لینک‌های راهنمای داخل پنل به دامنه شما می‌روند.</p> <div class="guide-callout guide-callout--tip"><strong class="guide-callout-label">نکته</strong><p>اگر <code>DOCS_BASE_URL</code> خالی باشد، همان <code>/help</code> روی سرور کاربر استفاده می‌شود.</p></div> <div class="guide-callout guide-callout--info"><strong class="guide-callout-label">راهنما</strong><p>بعد از هر تغییر در فایل‌های <code>docs/guide/pages/</code> باید دوباره <code>python scripts/build_guide.py</code> را اجرا کنید و خروجی را هم در گیت/سرور docs آپدیت کنید.</p></div>
