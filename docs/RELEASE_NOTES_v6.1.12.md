## PG overview UI

- Live up/down rate values right-aligned as «عدد واحد» (e.g. `254 کیلوبایت/ثانیه`).
- Multiple nodes: scrollable tabs under «نودها» (settings-style chrome, PG blue active).
- CPU/RAM metric boxes side-by-side on large screens; stacked on small screens.
- Progress percent has no chip; fill stays translucent for readability; bar tone
  follows the same ok/warn/err ladder as host gauge rings.
