## رنگ per-item · تب رنگبندی · پیش‌نمایش زنده

### پشتیبان‌ها و پرداخت

- رنگ جدا برای **هر پشتیبان** (فرم افزودن/ویرایش در `/tickets?supports=1`)
- رنگ جدا برای **هر کارت / درگاه / ولت** (تنظیمات مالی)
- گزینه **ارث از پیش‌فرض** یا رنگ صریح (سفید / آبی / سبز / قرمز)
- **ربات:** رنگ روی لیست پشتیبان و picker چند مقصد؛ 🎨 رنگ در تنظیمات ادمین

### تب رنگبندی (`/settings?tab=colors`)

- زیرتب‌ها: کاربر · پرداخت · ادمین · نماینده
- چیپ رنگ + select قبلی
- گروه‌های ادمین/نماینده جمع‌شونده
- خلاصه آیتم‌های پویا با لینک ویرایش
- **پیش‌نمایش mock زنده** همگام با زیرتب و تغییر رنگ
