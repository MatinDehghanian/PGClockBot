## اعلان‌ها · پرداخت چندگانه · عملیات گروهی · داشبورد

### اعلان‌ها (`/inbox` + داشبورد)

- دکمه **حذف** روی هر اعلان و آیتم صف کار
- مودال: **۲۴ ساعت** (snooze) یا **برای همیشه** (تا رفع مشکل)
- ذخیره per-staff در `panel_inbox_dismissals`

### پرداخت (تنظیمات مالی)

- چند **کارت**، **درگاه** و **آدرس ولت** با UI تمیز (+/−)
- فیلدهای legacy (`card_number`, `gateway_link`, …) sync می‌مانند
- **ربات:** انتخاب inline وقتی بیش از یک مقصد فعال است

### جداول

- Checkbox + انتخاب همه؛ نوار bulk فقط با انتخاب فعال
- **کاربران:** مسدود / رفع مسدودی
- **سفارشات:** تأیید / رد / لغو
- **پرداخت‌ها:** تأیید / رد
- **تیکت ربات:** بستن گروهی

### داشبورد

- **صف کار** بالای **فروش** (زیر دکمه‌های نمای کلی)
