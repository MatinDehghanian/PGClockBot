## بسته کاربران + اعلان‌ها + گزارشات مالی

منتشرشده روی `main` به‌عنوان یک نسخه یکپارچه (شامل کارهای قبلی 8.2.11–8.2.13 که روی main نبودند).

### کاربران (`/users`)

- نقش کنار نام؛ ستون سرویس / حجم / انقضا (تقریبی پلن + پرچم اعلان)
- فیلترها، کارت‌های خلاصه، مرتب‌سازی فوریت، نقطه اعلان (جدا از ریسک)
- اقدام سریع: پیام · تمدید · پیام گروهی روی فیلتر (سقف ۴۰، متن امن)
- Deep-link از مرکز اقدام، تیکت‌ها و مالی با اسکوپ همان فروشگاه

### مالی — تب گزارشات

- تب اول: گزارشات | رفتار کاربر | سفارشات | پرداخت‌ها | تحویل ناموفق
- مقایسه امروز · ۷ روز · ۳۰ روز؛ پنل فروش / کاربران / عملیات؛ روش پرداخت
- اسکوپ سخت `reseller_id` (مالک پلتفرم / فروشگاه نماینده)؛ fail-closed بدون `shop_owner_id`

### ربات

- ادمین و نماینده: گزارشات با سوییچ بازه
- پیام / تمدید سریع روی کارت کاربر (هم‌تراز وب)

### موبایل

- گرید گزارشات و خلاصه users ops روی viewport باریک

## امنیت

- لیست پلتفرم: `reseller_id IS NULL`؛ نماینده فقط مشتریان خودش
- ویرایش/مسدود/حذف Owner-only؛ ops در محدوده فروشگاه
- گزارشات و DM گروهی همیشه با اسکوپ سرورساید

## Deploy

In-panel update to `8.5.0` (no new migration). Hard-refresh the panel after update.
