## عملیات گروهی روی همه جداول واجد شرایط

همان منطق v8.7.7 (موازی با عملیات ردیف، فقط واجد شرایط، بج تعداد، مودال تأیید، حفظ تب) به جداول دیگر گسترش یافت:

| صفحه | عملیات گروهی |
|------|---------------|
| درخواست‌های نمایندگی | تأیید / رد |
| نمایندگان | حذف نمایندگی / حذف کاربر |
| پلن‌ها (کاربر + نماینده + کد هدیه) | روشن/خاموش / حذف |
| پیام گروهی | حذف تاریخچه |
| تیکت پنلی | بستن |
| کاربران / تمپلیت / گروه / هاست / نود پاسارگارد | مطابق عملیات ردیف |

جداول فقط‌خواندنی یا بدون عملیات ردیفی (داشبورد، وفاداری، principals، اینباند، ادمین‌های PG پیچیده) بدون bulk ماندند.
