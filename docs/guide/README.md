# راهنمای فارسی PGClockBot

منبع آموزش‌های داخل پنل (`/help`) و سایت استاتیک قابل‌نشر روی دامنه شخصی شما.

## ساختار

| مسیر | نقش |
|------|-----|
| `docs/guide/pages/*.md` | متن فارسی (منبع) |
| `docs/guide/theme/` | قالب و استایل هم‌زبان با وب‌پنل |
| `app/services/guide_catalog.py` | فهرست موضوعات، خلاصه برای آیکون ؟، نقش‌ها |
| `scripts/build_guide.py` | بیلد خروجی استاتیک |
| `app/web/static/guide/` | خروجی آماده (همراه آپدیت ربات می‌آید) |

## ویرایش محتوا

1. فایل Markdown مربوط را در `docs/guide/pages/` ویرایش کنید.
2. اگر موضوع جدید است، آن را به `guide_catalog.py` هم اضافه کنید.
3. بیلد بگیرید:

```bash
python scripts/build_guide.py
```

4. خروجی `app/web/static/guide/` را هم کامیت کنید.

### باکس‌های ویژه در Markdown

```md
:::tip
نکته کوتاه
:::

:::warn
هشدار
:::

:::error
**مشکل:** …
**علت رایج:** …
**راه حل:** …
:::
```

## روی سرور کاربر

بعد از نصب/آپدیت ربات:

`http://SERVER_IP:9000/help/`

آیکون دایره‌ای **؟** کنار تیتر صفحات، خلاصه همان بخش را نشان می‌دهد.

## روی دامنه شخصی

محتویات `app/web/static/guide/` را روی هاست/Nginx دامنه خودتان قرار دهید.  
جزئیات: صفحهٔ «انتشار راهنما روی دامنه خودتان» داخل خود راهنما، یا:

```env
DOCS_BASE_URL="https://docs.example.com"
```

تا لینک‌های ؟ پنل به دامنه شما بروند.
