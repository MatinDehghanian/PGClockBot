## نودها چیستند؟

نود همان سرور/نود اجرایی پاسارگارد است که ترافیک کاربران از آن عبور می‌کند. صفحهٔ `/pg/nodes` برای دیدن فهرست نودها و وضعیت سلامت آن‌هاست.

## چه کسی می‌بیند؟

مالک/ادمین و کسانی که در `pg_permissions` مجوز نود دارند (معمولاً `pg_staff`). نماینده فروشگاه این صفحه را فقط اگر نقش PG‌اش اجازه بدهد می‌بیند — تیک فروشگاه کافی نیست.

## چه کارهایی اینجا رایج است؟

- دیدن آنلاین/آفلاین بودن نود
- پیدا کردن نودی که خطا یا بار غیرعادی دارد
- هماهنگی با تغییرات زیرساختی قبل از اعلام قطعی به مشتری‌ها

### روتین پیشنهادی هنگام گزارش «اینترنت قطع است»

1. `/pg/nodes` را باز کنید و وضعیت نودها را ببینید.
2. اگر نودها لود نمی‌شوند، اول [نمای کلی PG](../pg-overview/index.html) و اتصال API را چک کنید.
3. اگر نود خاص قرمز/آفلاین است، همان را در پنل اصلی پاسارگارد و سرور بررسی کنید.
4. در صورت قطعی واقعی، مالک می‌تواند از [پیام گروهی](../broadcast/index.html) به کاربران خبر بدهد (این ابزار فقط برای `admin` است).

:::error
**مشکل:** نودها لود نمی‌شوند.

**علت رایج:** قطعی API پاسارگارد یا کمبود دسترسی نقش.

**راه حل:** نمای کلی PG و لاگ سرویس را چک کنید؛ با اکانت مالک مقایسه کنید.
:::

:::tip
خاموشی یک نود لزوماً یعنی همه پلن‌ها مرده‌اند نیست؛ بستگی دارد کاربران به کدام اینباند/گروه وصل‌اند.
:::

:::warn
تغییرات تخریبی نود را از روی عجله در پنل فروشگاه انجام ندهید؛ اگر پنل اصلی پاسارگارد منبع حقیقت زیرساخت شماست، آنجا را مبنا بگیرید.
:::

:::info
این صفحه جای ساخت پلن فروش نیست. بعد از پایدار شدن نود، برای فروش به [پلن‌ها](../plans/index.html) برگردید.
:::
