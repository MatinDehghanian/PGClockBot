## عیب‌یابی سریع

اول این سه دستور:

```bash
bash pgclock.sh status
bash pgclock.sh service
curl http://127.0.0.1:9000/health
```

## ربات جواب `/start` نمی‌دهد

**علت‌های رایج:** سرویس پایین است، دو پروسه هم‌زمان، توکن غلط، یا `ADMIN_IDS` اشتباه.

**راه حل:**
```bash
journalctl -u pgclockbot -f
```
باید چیزی شبیه `Bot online as @...` ببینید.

## وب‌پنل لاگین نمی‌شود

- رمز را از `pgclock.sh web` ریست کنید
- اگر پشت پروکسی هستید، `TRUST_PROXY` را فقط با آگاهی تنظیم کنید

## پاسارگارد قطع است

- `PG_BASE_URL` را بدون مسیر اضافی اشتباه چک کنید
- یوزر/رمز یا توکن را عوض کنید و ذخیره کنید
- از سرور به آدرس پنل PG پینگ/curl بگیرید

## آپدیت خراب شد

```bash
bash pgclock.sh update
```
اگر پوشه خراب شد، از بکاپ برگردانید؛ در بدترین حالت پوشه را با نام بکاپ جابه‌جا کنید و نصب تمیز بگیرید.

:::tip
برای تشخیص عمیق‌تر، در صورت نصب CLI سراسری: `pgclock doctor`
:::
