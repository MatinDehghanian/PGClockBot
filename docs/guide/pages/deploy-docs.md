## راهنما را روی دامنه خودتان بالا بیاورید

خروجی آمادهٔ راهنما در پروژه اینجاست:

`app/web/static/guide/`

همین پوشه یک سایت استاتیک کامل است (HTML/CSS/JS/فونت). می‌توانید همان را روی دامنه docs خودتان سرو کنید تا لینک‌های **؟** پنل به آنجا بروند.

این کار معمولاً مال **مالک/ادمین** سرور است.

## روش ۱ — ساخت و آپلود روی هاست

1. داخل پروژه:
```bash
python scripts/build_guide.py
```
2. محتویات `app/web/static/guide/` را روی هاست دامنه خودتان بریزید.
3. دامنه را به همان پوشه اشاره دهید؛ مثلاً `https://docs.example.com`

## روش ۲ — Nginx روی VPS

```nginx
server {
  listen 80;
  server_name docs.example.com;
  root /var/www/pgclock-docs;
  index index.html;
  location / {
    try_files $uri $uri/ $uri/index.html =404;
  }
}
```

محتویات `guide/` را در `/var/www/pgclock-docs` کپی کنید. برای HTTPS از certbot یا گواهی خودتان جلوی همین سرور استفاده کنید.

## وصل کردن آیکون ؟ پنل به دامنه شما

در `.env` سرور ربات:

```env
DOCS_BASE_URL="https://docs.example.com"
```

سرویس را ری‌استارت کنید. از این به بعد لینک‌های راهنمای داخل پنل به دامنه شما می‌روند.

:::tip
اگر `DOCS_BASE_URL` خالی باشد، همان `/help` روی سرور کاربر استفاده می‌شود — برای خیلی از نصب‌ها کافی است و نیازی به دامنه جدا نیست.
:::

## چه زمانی دامنه جدا لازم است؟

- می‌خواهید راهنما حتی وقتی پنل پشت VPN/فایروال است باز باشد
- چند پنل به یک منبع آموزش مشترک وصل شوند
- می‌خواهید docs را جدا از آپدیت ربات کش/CDN کنید

## چک‌لیست بعد از انتشار

1. `https://docs.example.com/` باز می‌شود؟
2. یک صفحه مثل `/start/` و `/roles/` ۲۰۰ می‌دهد؟
3. در پنل، لینک ؟ به همان دامنه می‌رود؟
4. بعد از تغییر مارک‌داون، دوباره `build_guide.py` زده‌اید و خروجی را آپلود کرده‌اید؟

### اشتباهات رایج

| علامت | احتمال | کار بعدی |
|-------|--------|----------|
| پنل هنوز `/help` می‌رود | `DOCS_BASE_URL` ست نشده | `.env` + ری‌استارت |
| زیرصفحه ۴۰۴ | `try_files` ناقص | نمونه Nginx بالا |
| متن قدیمی | بیلد نزده‌اید | `build_guide.py` دوباره |

:::info
بعد از هر تغییر در فایل‌های `docs/guide/pages/` باید دوباره `python scripts/build_guide.py` را اجرا کنید و خروجی را هم در گیت/سرور docs آپدیت کنید. فقط ویرایش مارک‌داون بدون بیلد، سایت استاتیک را عوض نمی‌کند.
:::

:::error
**مشکل:** دامنه باز است ولی لینک‌های داخل پنل هنوز `/help` می‌روند.

**علت رایج:** `DOCS_BASE_URL` ذخیره/ری‌استارت نشده یا اسلش انتهایی/پروتکل اشتباه است.

**راه حل:** مقدار را با `https://` و بدون مسیر اضافه بررسی کنید؛ سرویس ربات را ری‌استارت کنید؛ یک‌بار کش مرورگر را خالی کنید.
:::

:::warn
روی هاست، `try_files` باید برای مسیرهای پوشه‌ای مثل `/plans/` فایل `index.html` را پیدا کند. بدون آن، رفرش مستقیم زیرصفحه‌ها ۴۰۴ می‌دهد.
:::
