## بازنویسی عملیات گروهی

### موازی با دکمهٔ عملیات ردیف
- هر عملیات ردیف (غیر از خصوصی مثل رسید / ویرایش / پیام) معادل گروهی دارد
- فقط روی ردیف‌های **واجد شرایط** اعمال می‌شود (مثلاً از ۱۰ انتخاب، فقط ۲ قابل‌لغو → درخواست فقط برای همان ۲)
- اگر برای انتخاب فعلی هیچ عملیاتی ممکن نباشد، نوار گروهی کاری نشان نمی‌دهد

### UI
- کنار هر دکمهٔ گروهی، **دایرهٔ تعداد** واجد شرایط (fa-IR)
- تأیید فقط با **مودال پنل** (`panelConfirm`) — بدون `confirm` بومی

### حفظ تب
- `return_to` با query موجود (مثل `?tab=orders`) پاکسازی و redirect بدون `?` دوتایی
- بعد از bulk در همان تب/فیلتر می‌مانید

### پوشش
- کاربران: مسدود / رفع / تمدید / حذف (بر اساس دسترسی)
- مالی → سفارشات / پرداخت‌ها / **تحویل ناموفق (تلاش مجدد گروهی)**
- تیکت‌های بات: بستن
